I'm perox, a computer science student obsessed with robotics. I don't
settle for on-screen simulations — I want to see my ideas move in the
real world.

My approach is hands-on: I design and 3D-print mechanical parts, solder
the circuits myself, then write the software that brings it all to life.
My code runs on machines I built from scratch.

Goal: bring this maker mindset into the robotics industry.
